# 框子使用教程

> 本教程面向日常使用。命令行接口见 [CLI 手册](cli.md)；本文只讲输入框和热键。

## 唤起与输入

| 操作 | 效果 |
|---|---|
| `Alt+Space` | 唤起/隐藏输入框（默认热键，可改） |
| 打字 + 回车 | 提交（自动路由：见下节） |
| `Ctrl+Enter` | 强制提交（普通模式回车默认换行，极速模式相反——两档可切） |
| `Shift+Enter` | 换行 |
| `Ctrl+Shift+Enter` | 本条记为待办 |
| `Alt+Enter` | 本条走搜索 |
| `Esc` | 隐藏输入框 |

输入框左下角有工具条（默认：搜索 / 速记 / 待办 / 表情面板，设置 → 工具条可自定义勾选），鼠标党友好。

## 输入路由：框子怎么理解你打的字

回车后框子按以下顺序判断（符号显式优先）：

| 你输入的 | 框子理解为 | 例子 |
|---|---|---|
| 拖入了图片/文件 | 带附件的速记 | 截图直接拖进框 → 回车 |
| `-` 开头 | 待办 | `- 下午三点开会` |
| `@` 开头 | 启动/直达 | `@计算器`、`@我的项目目录` |
| `$` 开头 | 插件调用 | `$计算 1+2`（装了框子计算才有） |
| `/` 开头 | 搜索 | `/b站 人工智障`、`/天气` |
| 恰好是词表里的词 | 该词的动作 | `待办`、`日记`（内置词）；`高德地图`（默认词表） |
| 其他 | 兜底动作（默认=速记） | `下班买菜` → 落速记 |

**兜底动作可改**：设置 → 输入行为，把"无匹配时"改为记待办/搜索/不处理。

## 速记与待办

- 落盘格式（纯 Markdown，任何编辑器可读）：

```markdown
## 框子待办

- [ ] 2026-10-17 14:30:05
  下午三点开会

## 框子速记

- 2026-10-17 14:30:12
  下班买菜
```

- 时间戳自动加；多行整段保留
- 日记按周期分文件（默认按天，可切周/月）：`2026-10-17_day.md`，存在你设置的笔记库目录
- 打开今天日记：内置词 `日记`，或托盘菜单
- 图片/视频/音频/文档拖进输入框 = 附件：复制进附件目录 + 日记里留引用（单文件上限 200MB）

### 不唤起输入框的快捷记法

| 热键 | 效果 |
|---|---|
| `Ctrl+Alt+Z` | 把当前选中的文字直接记速记 |
| `Ctrl+Alt+X` | 复制当前选中后记速记 |
| `Ctrl+Alt+C` | 复制后发给豆包问 |

## 搜索

- `/关键词` → 默认引擎（默认百度）
- `/引擎名 关键词` → 指定引擎；只给引擎名（`/b站`）→ 开该站首页
- 引擎表内置：百度、谷歌、B站、微博、GitHub、小红书、豆包、翻译……设置 → 快捷搜索里改，或对 AI 说"以后搜索用知乎"
- 命令行等价：`kuangzi engine add 知乎 "https://www.zhihu.com/search?q=%s" --home https://www.zhihu.com`（URL 里的 `%s` 是搜索词占位）
- 引擎词也进输入框候选：`b站 直播` 直接搜

## 快捷启动（@与词表）

- `@词` 显式启动：词表 → path 挂载 → 应用/书签目录，层层找；多个候选弹菜单
- 应用已运行 → 激活窗口（不是重开）
- 默认词表带常用系统入口：计算器、任务管理器、控制面板、桌面、下载、回收站、系统截图……
- **加自己的词**：对 AI 说"把微信挂到框子"，或设置 → 快捷启动里加；命令行等价 `kuangzi word add 微信 "D:\Program Files\WeChat\WeChat.exe" --desc "微信桌面版"`（路径带空格要引号）
- 词表改完即生效：宿主下次唤起输入框时自动重载，不用重启

### 个人 PATH（挂载目录/文件）

把常用目录挂进框子，文件名即直达词（目录内容递归可搜，依赖目录自动剪枝）：

```
kuangzi path add "D:\客片"        # 或对 AI 说"把 D:\客片 挂到框子path"
kuangzi path rename 客片 婚纱客片  # 改个顺口的词
```

之后 `@婚纱客片` 直达；目录里的文件名也能搜到。

## 一键直达（CapsLock 组合键）

按住 CapsLock + 字母/符号 = 一个动作，出厂示例：

| 键 | 动作 |
|---|---|
| `CapsLock+Space` | 显示/隐藏输入框 |
| `CapsLock+/` | 打开笔记目录 |
| `CapsLock+J` | 计算器（等价 `@计算器`） |

设置 → 一键直达里自由绑定：任何词表词、引擎、插件动作、系统动作都能绑上去。

## 语音

按住右 Ctrl 说话（智慧语音，可改键），说完松手——识别结果进输入框走同一套路由。口令式使用：话里带路由词（"待办"“打开"）自动按语义分发。详细配置见设置 → 智慧语音。

## 设置中心

托盘右键 → 设置（或内置词 `设置`）。十个 Tab：笔记、系统、闪窗、快捷搜索、快捷启动、一键直达、智慧语音、快捷键、工具条、插件。

**快捷键总表**是全部热键的唯一清单（含来源标注：内置/词表/引擎/插件，哪些可改一目了然）。

## 多设备与数据

- 笔记库目录自己选（默认 OneDrive\框子笔记库），同步盘同步到哪，哪台电脑就能接着记
- 每台设备写自己的分区（`kuangzi-data/<设备名>/`），互不冲突；查询时全量合并
- 历史日记积多了：`kuangzi archive` 按月归档（先预览再执行），或对 AI 说"帮我归档上个月的日记"

## 遇到问题

| 现象 | 处理 |
|---|---|
| 热键唤不起 | 检查是否被其他软件占用（设置里换键）；管理员权限的程序里使用需以管理员运行框子 |
| 插件装了没反应 | 设置 → 插件 → 刷新（或重启框子）；目录名要与插件 id 一致 |
| 日记在哪个文件 | 托盘 → 打开今日日记；或问 AI"今天的日记路径" |
| 终端敲 `kuangzi` 没反应 | cmd/PowerShell 直接敲需等新开的终端（PATH 刚写入）；旧会话里用完整路径或 `kuangzi.cmd` |
| 卸载 | 开始菜单 → 框子 → 卸载框子；可选是否同时删除数据（`~/.kuangzi/data/kuangzi-app/`，笔记库不受影响） |

## 隐私说明

- 笔记、附件、配置全部存本地（笔记库目录自选；配置在 `~/.kuangzi/data/`），无云服务、无遥测
- 语音识别用系统自带的 Windows 语音识别，不出网
- 插件的敏感权限（读剪贴板/前台窗口）只在插件 manifest 显式声明且你知情时才下发，设置 → 插件可查看每个插件的权限声明

## 从源码构建

想自己编译而不装发行版：

1. 安装 [AutoHotkey v2](https://www.autohotkey.com/)（官方安装包自带 Ahk2Exe 编译器）
2. 仓库根运行：`powershell -ExecutionPolicy Bypass -File tools\build.ps1`
3. 四个产物落 `build\`：`kuangzi.exe`（宿主）、`kuangzi-cli.exe`（CLI）、`kuangzi-uninstall.exe`（卸载器）、`kuangzi-setup-v<版本>.exe`（安装器）

也可不编译直接跑源码：`AutoHotkey64.exe kuangzi.ahk`（CLI 源码态无终端输出属正常，编译版才有）。
